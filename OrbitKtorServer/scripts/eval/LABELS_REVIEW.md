## Point 9 — semantic search relevance

Corpus: every PUBLIC event after loading db/schema.sql, db/seed.sql (as committed) and db/events_catalog.sql; 61 events (9 seed, 52 catalog).

Rule: An event is relevant when a person typing the query would want it in the results because its main activity matches what the query asks for. A single shared word is not enough (the hackathon mentions 'hrana i pice' but is not about food). 'borderline' lists events where reasonable people disagree; the main metrics count them as not relevant, a second run counts them as relevant.

Frozen thresholds: `MIN_LEAD = 0.05`, `RELATIVE_MARGIN = 0.03`, `MAX_RELATED = 10`.
